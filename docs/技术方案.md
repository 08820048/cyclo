# Cyclo 技术方案

## 1. 技术栈

- Swift 6 工具链(语言模式 v5),SwiftPM 构建,不用 Xcode 工程;与 Runnock 一致
- AppKit 负责窗口、菜单栏、生命周期;SwiftUI 只用于设置界面和背景渲染
- 最低 macOS 26;`LSUIElement` 菜单栏应用(无 Dock 图标)
- 分发:Developer ID 签名 + 公证,后续接 Sparkle;免费期不接收费
- 不上 App Store(需要辅助功能权限、Apple Events,沙盒不允许)

## 2. 模块

```

    Backdrop        背景描述(纯色 / 渐变 / 图片)与颜色解析
    WindowPreset    窗口规格、解析 "1280x800"

    SessionJournal  恢复日志模型与落盘(JSON)
  Cyclo/          App
    AppDelegate         启动、崩溃恢复、快捷键注册
    MenuBarController   状态栏图标与菜单
    StageController     进入/退出场景的编排,逐步写恢复日志
    BackdropWindows     每块屏幕一层桌面遮罩
    AppHider            隐藏/恢复其他 App
    DockController      Dock 自动隐藏(System Events)

    HotKey              Carbon 全局快捷键
    SettingsWindow      SwiftUI 设置界面
  cyclo-checks/   轻量自检(`swift run cyclo-checks`)
```

## 3. 关键实现

### 3.1 桌面遮罩
- 每个 `NSScreen` 一个无边框 `NSWindow`,层级 `CGWindowLevelForKey(.desktopIconWindow) + 1`:高于桌面图标和壁纸,低于所有普通窗口
- `collectionBehavior = [.canJoinAllSpaces, .stationary, .ignoresCycle, .fullScreenNone]`,切换桌面空间时不跟随动画、不进 ⌘Tab
- 监听 `NSApplication.didChangeScreenParametersNotification`,接显示器/改分辨率时重建
- 不修改 Finder 的 `CreateDesktop`,不碰桌面文件 → 无需恢复,天然安全

### 3.2 隐藏其他 App
- 遍历 `NSWorkspace.shared.runningApplications`,条件:`activationPolicy == .regular`、`!isHidden`、不是目标 App、不是自己
- 先把这些 App 的 bundle id / pid 写进恢复日志,再调用 `hide()`
- 退出时只 `unhide()` 日志里的 App;最后重新激活目标 App

### 3.3 Dock 自动隐藏
- 读原值:`CFPreferencesCopyAppValue("autohide", "com.apple.dock")`
- 改值:AppleScript `tell application "System Events" to set autohide of dock preferences to true`,有动画、不重启 Dock
- 首次使用会弹 Apple Events 授权(Info.plist 写 `NSAppleEventsUsageDescription`)
- 原本就是自动隐藏则什么也不做,也不记录

### 3.4 勿扰
- 系统没有公开 API。让用户在"快捷指令"里建两个指令(打开/关闭勿扰),设置里填名字
- 进入/退出时执行 `/usr/bin/shortcuts run <名字>`;没填就跳过

### 3.5 窗口规格
- `AXUIElementCreateApplication(pid)` → `kAXFocusedWindowAttribute`(取不到则 `kAXMainWindowAttribute`)
- 记录原 `kAXPositionAttribute` / `kAXSizeAttribute` 到日志 → 设置尺寸 → 按实际尺寸重新计算居中位置并设置
- 居中区域:窗口所在屏幕去掉菜单栏的区域(Dock 已隐藏,不扣 Dock)
- 预设大于可用区域时等比缩小并提示;App 自己限制了最小/最大尺寸时以实际尺寸为准
- 规格单位是点(pt),Retina 下像素翻倍(1280×800 pt = 2560×1600 px),设置界面注明
- 需要辅助功能权限:`AXIsProcessTrustedWithOptions` 按需提示;没有权限时跳过此步,其他步骤照常

### 3.6 恢复日志(可逆性的核心)
- 路径:`~/Library/Application Support/Cyclo/session.json`
- 每一步改动**之前**先把"还原所需信息"追加写入日志,保证任意时刻崩溃都能还原
- 退出流程按相反顺序还原:窗口 → Dock → 显示 App → 勿扰关闭 → 移除遮罩;完成后删除日志
- 启动时若日志存在,说明上次没正常退出,自动执行还原
- 遮罩窗口随进程消失,不需要记录

### 3.7 全局快捷键
- Carbon `RegisterEventHotKey`,默认 ⌃⌥⌘S;不需要辅助功能权限

### 3.8 目标 App 判定
- 菜单栏点击和全局快捷键都不会激活本 App(`LSUIElement`),所以进入时 `NSWorkspace.frontmostApplication` 就是用户正在用的 App
- 前台是 Finder 或本 App 时:不调整窗口,只做桌面清理

## 4. 权限

| 权限 | 用途 | 何时请求 | 拒绝后 |
|---|---|---|---|
| 辅助功能 | 调整目标窗口尺寸 | 开启"窗口规格"并首次进入场景时 | 跳过窗口调整 |
| Apple Events → System Events | 切换 Dock 自动隐藏 | 首次进入场景 | 跳过 Dock |
| 快捷指令 | 勿扰 | 用户配置后 | 跳过 |

## 5. 构建与验证

- 构建:`scripts/build-app.sh [debug|release]` → `build/Cyclo.app`
- 自检:`swift run cyclo-checks`
- SwiftUI 宏需要 Xcode 工具链:脚本自动设置 `DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer`

## 6. 已知限制 / 待验证

- 桌面小组件(macOS 14+)是否被遮罩完全盖住,需要实机确认
- 全屏 App(独占 Space)下遮罩不可见,也不需要
- Cyclo Manager 开启时,左侧缩略图条属于系统层,遮罩盖不住;M2 评估是否临时关闭 Cyclo Manager
