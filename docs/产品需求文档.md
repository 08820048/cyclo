# Cyclo 产品需求文档

> Cyclo,名字取自摄影棚的无影墙(cyclorama)。macOS 原生菜单栏工具,最低 macOS 26,先免费发布验证需求。

## 1. 一句话

一键把 Mac 切换成"干净的录屏/截图舞台",用完一键恢复原样。

## 2. 要解决的问题

给产品截图、录演示视频、开会共享屏幕时,真实桌面会出现在画面里:

- 杂乱的桌面图标、文件名(可能是客户名、项目代号)
- 私人壁纸
- 菜单栏一排第三方图标、Wi-Fi 名、时间、电量
- 录到一半弹出的微信/Slack/邮件通知
- Dock 里装了什么 App
- 其他 App 的窗口
- 目标窗口尺寸每次都不一样,截图规格不统一

现状是每次手动收拾、录完再手动恢复,麻烦且容易漏。

## 3. 目标用户

| 用户 | 典型场景 | 最在意 |
|---|---|---|
| 独立开发者 / 产品经理 | 官网截图、App Store 截图、更新日志 GIF | 窗口规格统一、画面干净 |
| 内容创作者 / 讲师 | 教程录屏 | 不被通知打断、背景好看 |
| 销售 / 售前 | 客户演示、共享屏幕 | 不泄露其他客户信息 |
| 设计师 | 作品集展示 | 背景与品牌一致 |

## 4. 产品原则

1. **可逆是底线**:进入场景前记下所有被改动的状态,退出时完整还原;即使 App 崩溃或被强退,下次启动也能还原。
2. **不碰用户数据**:不移动、不删除桌面文件,只"盖住"。
3. **一键**:菜单栏一次点击或一个全局快捷键完成进入/退出。
4. **轻**:常驻内存目标 < 50 MB,空闲 CPU ≈ 0。
5. **权限按需**:不需要辅助功能权限也能用核心功能;窗口规格等功能需要时再请求。

## 5. 功能范围

### M1 MVP(本次实现)

- **一键干净场景**(以"进入时的前台 App"为目标 App)
  - 桌面遮罩:每块屏幕铺一层展示背景,盖住桌面图标、桌面小组件和私人壁纸;背景可选纯色 / 内置渐变 / 自定义图片
  - 隐藏其他 App:除目标 App 外全部隐藏(只隐藏原本可见的,退出时只恢复这些)
  - Dock 自动隐藏(记录原设置,退出时还原)
  - 勿扰:进入/退出时各运行一个用户指定的"快捷指令"(系统没有公开的勿扰 API)
- **窗口规格预设**:把目标 App 的前台窗口调成精确尺寸并居中(1280×800、1440×900、1920×1080、2560×1600 等,可自定义);退出时还原原位置和尺寸
- **退出时完整恢复** + **崩溃恢复**:状态写入恢复日志,下次启动发现未正常退出则自动还原
- 菜单栏图标 + 菜单;全局快捷键 ⌃⌥⌘S 切换
- 设置窗口:背景、窗口规格、开关各项、勿扰快捷指令名

### M2

- 干净菜单栏:盖一层"假菜单栏",只保留目标 App 菜单 + 可选固定时间(9:41)/ 满电图标
- 目标 App 只保留前台窗口,其余窗口最小化
- 多个场景预设(例如"App Store 截图""教程录屏""客户演示"),每个场景一套配置,可分别绑快捷键
- 鼠标点击高亮、按键显示

### M3

- 敏感信息打码:手动框选区域打码;Vision OCR 识别邮箱/手机号自动打码
- 浏览器隐私:提示/自动隐藏书签栏(按浏览器适配)
- 场景导入导出(JSON)

### 探索

- 虚拟显示器"舞台屏"(CGVirtualDisplay 私有 API,风险高,单独评估)

### 不做

- 录屏/截图本身(交给系统、CleanShot、Screen Studio)
- 后期剪辑

## 6. 体验流程(M1)

1. 用户切到要演示的 App
2. 按 ⌃⌥⌘S(或点菜单栏图标 → 进入舞台)
3. 0.3 秒内:桌面变成展示背景,其他 App 隐藏,Dock 隐藏,勿扰开启,目标窗口调到预设尺寸居中
4. 菜单栏图标变为"进行中"状态
5. 录完再按 ⌃⌥⌘S → 全部恢复

## 7. 成功指标(免费验证期)

- 下载量、7 日留存(一周内第二次进入场景的比例)
- 每周平均进入场景次数
- 官网 Windows 候补名单人数
- 用户反馈中"愿意付费"的比例

## 8. 竞品(2026-11 调研)

| 产品 | 做了什么 | 和 Cyclo 的重叠 |
|---|---|---|
| Swab(swab.shafer.llc) | 一键清桌面:隐藏图标、背景遮罩、设分辨率、摆放窗口、先写 JSON 快照再还原;内置截图录屏、鼠标高亮 | 几乎完全重叠,含"先落盘再改"的思路 |
| CleanSlate(getcleanslate.app) | 隐藏图标/窗口/通知/菜单栏、渐变背景、多场景、检测到共享屏幕自动开启 | 偏会议共享屏幕场景 |
| HotShot | 截图录屏工具,自带"先布景":隐藏图标、菜单栏、Dock、精确窗口尺寸、拍完还原 | 作为截图工具的附属功能 |
| CleanShot X / Matte / Screen Studio | 截图录屏 + 后期背景美化 | 解决的是后期,不是录的那一刻 |

结论:"一键干净 + 可还原"已经不是差异点,只是入场门槛。Cyclo 的差异要在 M2/M3 里找,候选方向:

- 做到最好的"假菜单栏"(固定 9:41、满电、只留目标 App 菜单),竞品大多只能整条隐藏
- 敏感信息实时打码(OCR 识别邮箱、手机号),对销售演示、客服教程很有用
- 中文用户与国内产品场景:微信、飞书、钉钉的通知和窗口处理,中文界面与文档
- 虚拟显示器"舞台屏":真实桌面完全不动

## 9. 风险

| 风险 | 应对 |
|---|---|
| 恢复失败导致用户桌面状态丢失 | 恢复日志先落盘再改动;每一步独立可还原;自检覆盖 |
| 苹果收紧窗口层级/AX 行为 | 核心功能只用公开 API;私有 API 只放在可选功能 |
| CleanShot / 系统内置同类功能 | 做完整流程(场景 + 规格 + 恢复),而不是单点 |
| 勿扰无公开 API | 用快捷指令桥接,引导用户一次性配置 |
